# Identity component extraction evidence

The existing identity palette, fonts, portal and product CSS remain the design
source. This slice turns the template into eleven reusable HTML renderers and
composes the arrival and feedback examples from them. It changes no taste lock.

The six captures bind to the source hashes in `manifest.json`. Desktop retains
the asymmetric headline/portal hierarchy. Phone places the arrival action before
the portal. The feedback page uses the calm product register; its retry action
fits the first phone viewport after reducing specimen-only spacing.

The browser checks native Tab/Enter and radio arrow keys, focus recovery, pending
button dimensions, disabled activation, loaded assets, overflow and finite motion.
Reduced-motion captures contain no animations. The examples use local state only.
The retained Auth report remains the reference evaluation; these images prove
component extraction and specimen behavior, not a new aesthetic approval or live
authentication/security result.
