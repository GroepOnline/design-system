# Research inbox

Dropzone for interesting UI, motion, 3D, interaction and visual references found anywhere.
An inbox item is **not** a production component and does not need an immediate ChefGroep use-case.

Use `./ds inbox add <url>` to capture first, curate later. `items.jsonl` keeps one small record per find with provenance, type, tags, note and status.

Promotion path:

`new -> researched -> specimen -> candidate -> selected`

The first three steps may stay purely exploratory. Selection into a production component remains explicit through the existing locked catalog model.
