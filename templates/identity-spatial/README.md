# ChefGroep identity template

The static example reproduces the accepted identity composition and its refined
SVG/motion. It is explicitly labeled as a template and has no simulated login or
invented account state. Start a real product from its domain/API contract.

- `tokens.css`: canonical shipped template palette, typography and focus tokens.
- `product.css`: versioned source specimen of the auth page/control system.
- `component-contracts.json`: required behavior for reusable product primitives.
- `fonts/`: self-hosted licensed fonts; retain their licenses when copying.
- `../../extensions/chefgroep/assets/identity-mark.svg`: canonical vector source.

Copy only the relevant composition/control definitions into a consumer; record
the source revision and hashes. Never import auth code or filesystem account
state. A generic design scaffold is not deploy-ready auth. Real loading, errors,
consent, revoke and security behavior remain required before product acceptance.

Origin: `GroepOnline/chefgroep-auth@405e8aa`, refined by the design-standard task.
The exact visual direction is approved for ChefGroep identity. Other products
reuse the quality process and an appropriate profile rather than this literal
portal. No untested dark theme is silently promised.
