# Quality contract

Signaal separates deterministic quality from taste review.

**Gate A, blocking:** catalog integrity, runtime-package integrity, accessible names/labels, valid quality manifests, responsive contract coverage and reduced-motion rules.

**Gate B, review evidence:** hierarchy, composition, density, restraint, originality and interaction quality. These are reviewed against `taste-rubric.json` using reference/before/after plus desktop and phone evidence. They are not reduced to an automatic model score.

`visual-contracts.json` is the representative review matrix. It must cover every canonical component category and every composition pattern. The capture script creates light/dark screenshots at phone and desktop sizes when a Chromium-compatible browser is available.
